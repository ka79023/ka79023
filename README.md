### [Arabic Punctuation Restoration](https://github.com/ka79023/Arabic-Punctuation-Restoration)

An NLP project developed for the Daal Challenge to restore punctuation in Arabic text using AraBERT, model ensembling, and pseudo-labeling.

- **Technologies:** Python, PyTorch, Hugging Face Transformers
- **Kaggle leaderboard score:** 0.674
- Competition datasets are not included due to sharing restrictions.
